Capture students’ **invisible labor** in DP1 (exploring questions and data) and DP3 (narrative work), and give instructors a way to **show assignment prompts** and **give feedback on the whole project** — weekly intermediate artifacts as well as the final story.

## Sprint 1 — 2 Sep to 14 Sep

**Goal:** Ship the cheap wins and the minimum assignment loop so later instructor features have something to attach to.

Already in the product (do not rebuild): workspace auto-persists via the API; a Submit button exists but navigates to `/construction`; instructor notes exist but are not item-anchored; `logAction` covers some UI events; zoom exists but the range is limited.

| Item | Why this sprint |
| --- | --- |
| Copy/paste as notes + multiselect | Easy, daily UX, unblocks Sprint 2 grouping |
| Assignment prompt in workspace | Instructors need the prompt visible when the project starts |
| Save workspace snapshots | Checkpoint for weekly updates; pairs with submit |
| Submit assignment | Replace the stub; snapshot current workspace for the instructor |
| Higher zoom / low-res bigger icons | Easy visual fix, high student payoff |
| Basic instrumentation | Event coverage for RQ, narrative, save, submit — capture invisible labor |

**Sprint 1 done when:** a student can see a prompt, copy notes, multi-select cards, save and submit, and those events are logged. Instructor View Workspace can at least see that a submission exists (history/delta can wait for Sprint 2).

## Sprint 2 — 15 Sep to 28 Sep

**Goal:** Instructors can review weekly work and comment on it. DP1 tools start capturing early labor.

| Item | Why this sprint |
| --- | --- |
| Submission history + delta | Karen’s weekly-update request; depends on Sprint 1 save/submit |
| Anchor instructor notes to items | Feedback on intermediate artifacts, not only a sidebar dump |
| Escalate / resolve threads | Turns notes into a closable conversation |
| RQ submit / export | DP1 labor made visible and hand-in-able |
| AI assistance for RQs | DP1 support without replacing student questions |
| Group using multiselect | Natural follow-on to Sprint 1 selection |

**Sprint 2 done when:** an instructor can open a student’s workspace, see what changed since the last submit, and leave a note on a specific card that the student can resolve.

## Sprint 3 — 29 Sep to 12 Oct

**Goal:** DP3 narrative work is first-class in the UI, not a one-shot Generate story action.

| Item | Why this sprint |
| --- | --- |
| Always-on narrative structure browser | Same presence as RQ and feedback panels |
| Quick preview / compare scaffolds | Students can try structures without committing blindly |
| Pin story browser (focus / side-by-side) | Room to write without losing RQ/narrative context |
| Manual add/export visuals into the story | Invisible narrative labor without waiting on the LLM |
| Comment on generated story | Feedback on the final artifact |
| Feedback as scaffold annotations | Tie AI/instructor feedback to structure, not a separate list |
| Formatting controls | Student polish before 10/19 |
| Seamless JupyterHub | High friction today; isolate if it slips |

If the JupyterHub “add new server” removal is blocked on the Hub side, document the workaround and move the rest of Sprint 3 rather than slipping the narrative browser.

**Sprint 3 done when:** a student can pick a structure from a persistent browser, preview another, build or generate a story, comment, and format — and an instructor can still see weekly submits from Sprint 2.

## Risks

- **Save vs auto-persist.** The app already writes workspace state continuously. “Save” should mean a named snapshot (weekly checkpoint), not a second persistence layer.
- **Submit without snapshots** makes submission history fake. Keep B2 and B5 in the same sprint.
- **JupyterHub** is a separate service (`CAST_ext`). Treat D4 as isolatable.
- **Content vs code.** Micro-assessments and sample stories need PI-authored material; do not block 10/19 on them.
- **Scope vs six weeks.** Wizard, grader, multinarrative, and Prolific are post-midterm unless Sprint 3 finishes early.
